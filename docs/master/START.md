# Homepage Master

Stand: 1. Oktober 2026. Dieses Repository führt die persönliche Homepage von Timo Schreck fort.

## Verbindliche Richtung

Strategischer Projektpartner für Geschäftsentwicklung und Digitalisierung. Ein fester Ansprechpartner, der das Vorhaben versteht und passende Expertise koordiniert. Kundenziele und Kundenperspektive im Mittelpunkt.

Die öffentliche Homepage bleibt schmal: Einstieg, drei Leistungsfelder, persönliches Vertrauen, Kontakt. Ziel ist Kontaktaufnahme. Ausführliches Angebot und Projektcheck bleiben Gesprächsgrundlagen.
